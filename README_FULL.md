# CINEMA AI — دليل التشغيل والإنتاج الكامل (README FULL)

## 1. نبذة عن المحرك
محرك **CINEMA AI** هو محرك موحد لتوليد الفيديو بالذكاء الاصطناعي مبني فوق النموذج الأساسي **Wan 2.1 T2V 1.3B** (`Wan-AI/Wan2.1-T2V-1.3B-Diffusers`).
يدعم:
- **تعدد اللغات واللهجات**: فهم دلالي للعربية الفصحى ومختلف اللهجات (المصرية، الشامية، المغربية، الخليجية، السودانية) والإنجليزية واللغات العالمية.
- **القدرات البصرية الخمس**: Cinematic Realistic, Realistic Human, 3D Cartoon, 2D Cartoon, Anime.
- **فيديو مستمر من 5 إلى 30 ثانية**: بتقسيم المقاطع وتتبع استمرارية الشخصيات وتجميعها آلياً.
- **تخزين المهام الدائم**: حفظ واسترجاع المهام ذرياً عبر `var/cinema_jobs/`.

## 2. التشغيل والتحقق السريع (Smoke Test & E2E)
لتشغيل جميع الاختبارات الآلية (235 اختباراً ناجحاً بنسبة 100%):
```bash
bash run_all.sh
```

## 3. مسار التدريب والتوليد السحابي
- **للتوليد السريع المجاني**: شغّل `python3 free_inference.py`.
- **لتدريب LoRA على GPU**: شغّل `python3 train_lora.py --style cinematic_realistic --steps 100`.
- **لتشغيل نوتبوك Google Colab بنقرة واحدة**: افتح `colab_train.ipynb` في Colab واختر بيئة T4 GPU.
- **لتشغيل كيرنل Kaggle**: اتبع الخطوات في `kaggle_setup.md` واستخدم `kaggle_kernel/`.
